- **[强制] 空值边界明确**: 公共 API 明确 nullable 语义; 不用 `null` 表达多种业务状态.
- **[强制] 异常分层**: 区分业务异常, 参数错误和系统异常; 不捕获后仅打印日志继续执行.
- **[强制] 事务边界清晰**: 数据库写操作必须明确事务边界, 避免在事务中执行不可控外部 I/O.
- **[默认] 依赖注入**: 服务依赖通过项目既有 DI 框架或构造函数注入, 避免隐藏全局状态.
- **[默认] 测试贴近边界**: 核心业务逻辑使用单元测试覆盖; 持久化和集成路径使用项目既有集成测试模式.
