- **[强制] 遵循既有风格**: 修改代码时优先匹配项目现有命名, 分层, 错误处理和测试组织方式.
- **[强制] 小步变更**: 优先做局部, 可验证, 易回滚的修改; 不把无关重构混入功能变更.
- **[强制] 明确验证**: 修改后运行与变更范围匹配的测试, lint 或构建命令; 无法运行时说明原因和替代检查.
- **[默认] 类型与边界清晰**: 公共接口, 配置项, 持久化结构和协议字段应保持兼容性, 变更时说明迁移影响.
